# timezone-overlap

여러 나라에 흩어진 사람들끼리 모일 시간을 잡을 때, **모두가 가능한 시간대를 눈으로 찾는** 한 장짜리 웹페이지.

빌드 없음 · 의존성 0 · 서버 없음. `public/index.html` 파일 하나가 전부다.

## 왜 이렇게 생겼나

시차 계산을 숫자표로 보여주면 결국 사람이 머릿속으로 교집합을 구해야 한다. 그 일을 화면이 대신하도록 두 층으로 나눴다.

- **하늘 띠** — 각 지역의 하루를 실제 하늘색(자정 남색 → 새벽 산호빛 → 한낮 → 해질녘 보랏빛)으로 칠한다. 지역마다 오프셋만큼 어긋나 쌓이므로 **어긋남 자체가 보인다.** "왜 안 되는지"를 설명한다.
- **Everyone 띠** — 맨 위 한 줄. 전 지역의 판정을 겹쳐 **가능한 구간만 밝게** 켠다. "언제 되는지"를 답한다.

판정은 세 단계뿐이다. 지역별로 따로 주지 않고 공통 규칙 하나를 쓴다.

| 판정 | 현지 시각 |
|---|---|
| Works | 09:00 – 21:00 |
| Maybe | 07:00 – 09:00, 21:00 – 24:00 |
| No | 00:00 – 07:00 |

전체 판정은 **가장 나쁜 지역**을 따른다. 한 명이라도 No면 No다.

## 조작

- 띠 위를 드래그하면 세로 커서가 움직이고 전 지역 시각이 동시에 바뀐다 (15분 단위).
- 각 지역의 시각을 클릭하면 그 지역 기준으로 직접 입력할 수 있다. "파리 15시로 맞춰보자"가 되는 지점.
- 키보드: 커서에 포커스를 준 뒤 `←` `→` 15분, `Shift +` 화살표 1시간, `Home`/`End` 하루 양끝.
- `Add a place`로 IANA 타임존 전체 중에서 지역을 추가한다.
- `Copy summary`는 채팅에 그대로 붙여넣을 표를 만든다.

## URL

상태는 전부 URL 해시에 담긴다. 서버가 없으니 **링크 공유가 곧 구성 공유**다.

```
/#tz=Asia/Seoul,Europe/Paris,America/Santiago,Pacific/Auckland&t=2026-08-23T11:00Z
```

- `tz` — IANA 타임존 쉼표 목록. **목록의 첫 번째가 기준(anchor)**이라 상단 큰 시각과 하단 축 눈금이 그 지역 기준으로 표시된다.
- `t` — 절대 시각(UTC). 지역 구성과 무관하게 같은 순간을 가리킨다.

`tz`가 없으면 기본 4개 지역(서울·파리·산티아고·크라이스트처치), `t`가 없으면 현재 시각으로 뜬다.

## 서머타임

`Intl.DateTimeFormat`의 IANA 데이터를 그대로 쓰므로 **날짜를 바꾸면 오프셋이 따라온다.** 라이브러리 없음.

기본 4개 지역 중 셋이 서머타임을 쓰고 남반구 둘은 방향이 반대라, 8월과 1월의 시차가 서로 다르다.

| | 8/23 (UTC 11:00) | 1/23 (UTC 11:00) |
|---|---|---|
| 서울 | 20:00 | 20:00 |
| 파리 | 13:00 (CEST +2) | 12:00 (CET +1) |
| 산티아고 | 07:00 (−4) | 08:00 (−3) |
| 크라이스트처치 | 23:00 (+12) | 익일 00:00 (+13) |

서머타임 전환일의 23시간·25시간짜리 하루도 창 길이에 반영된다. 인도(+5:30)·채텀제도(+12:45) 같은 반시간 오프셋도 정상 동작한다.

## 로컬 실행

정적 파일이라 아무 서버나 된다.

```sh
cd public && python3 -m http.server 8777
```

## 배포

Cloudflare (b7g-blog와 같은 방식 — `wrangler.jsonc`의 assets 디렉토리).

```sh
npx wrangler deploy
```

빌드 단계가 없으므로 `public/` 이 그대로 올라간다.

## 알아둘 것

- 띠의 색은 **하루의 모양을 보여주는 연출이지 실제 일출·일몰 데이터가 아니다.** 위도와 계절에 따른 낮 길이 변화는 반영하지 않는다.
- 크라이스트처치는 `Pacific/Auckland`와 같은 타임존이다. 표시 이름만 바꿔 쓴다 (`RENAME` 상수).
- 지역이 많아지고 경도가 넓게 퍼지면 Works 구간이 아예 없는 게 정상이다. 기본 4개 지역이 그렇고, 그때는 Maybe 구간이 답이 된다.
