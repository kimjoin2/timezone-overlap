# timezone-overlap

여러 나라에 흩어진 사람들끼리 모일 시간을 잡을 때, **모두가 가능한 구간을 눈으로 찾는** 한 장짜리 웹페이지.

빌드 없음 · 의존성 0 · 서버 없음. `public/index.html` 파일 하나가 전부다.

## 왜 이렇게 생겼나

시차를 숫자표로 보여주면 결국 사람이 머릿속으로 교집합을 구해야 한다. 그 일을 화면이 대신한다.

- **지역 띠** — 각 사람이 언제 가능한지를 공통 24시간 위에 칠한다. 지역마다 오프셋이 다르니 막대가 서로 어긋난 자리에 놓이고, **그 어긋남이 곧 시차**다.
- **Everyone 띠** — 맨 위 한 줄. 전 지역의 판정을 겹쳐서 **다 겹치는 구간만 켠다.** 켜진 자리가 답이다.

색 언어는 두 곳이 같다. 아래 줄은 "이 사람이 언제 되는지", 맨 위 줄은 "모두가 언제 되는지"를 같은 색으로 말한다.

> 초기 버전은 띠에 실제 하늘색(자정 남색 → 새벽 → 한낮 → 노을)을 칠했다. 보기엔 좋았지만 **일출·일몰이 상수로 박힌 가짜 데이터**였고(위도·계절 무시), 해가 떴는지는 약속을 잡는 데 쓰이지 않는다. 쓰이는 건 각자가 몇 시부터 몇 시까지 되는지다. 그래서 띠가 그걸 보여주도록 바꿨다.

## 판정

지역마다 **자기 현지시간으로** 가능 시간을 갖는다. 기본은 09:00–22:00이고 `07:00–01:00`처럼 자정을 넘겨도 된다.

| 판정 | 뜻 |
|---|---|
| Works | 그 사람의 가능 시간 안 |
| Maybe | 가능 시간 바깥이지만 여유폭 안 |
| No | 그 밖 |

**여유폭(Flex)** 은 "가능 시간 바깥으로 이만큼은 무리해볼 수 있다"는 전체 공통값이다(기본 2시간). 지역마다 범위를 두 개씩 받지 않으려고 이렇게 뒀다.

전체 판정은 **가장 나쁜 지역**을 따른다. 한 명이라도 No면 No다.

## 조작

- 띠 위를 드래그하면 세로 커서가 움직이고 전 지역 시각이 동시에 바뀐다 (15분 단위).
- 이름 아래의 가능 시간(`09:00–22:00`)을 클릭하면 그 지역 기준으로 고친다. Enter나 바깥 클릭으로 확정, Escape로 취소.
- 각 지역의 **시각**을 클릭하면 그 지역 기준으로 순간을 지정한다. "파리 15시로 맞춰보자"가 되는 지점.
- 키보드: 커서에 포커스를 준 뒤 `←` `→` 15분, `Shift +` 화살표 1시간, `Home`/`End` 하루 양끝.
- `Add a place`로 IANA 타임존 전체 중에서 지역을 추가한다.
- `Copy summary`는 채팅에 그대로 붙여넣을 표를 만든다.

## URL

상태는 전부 URL 해시에 담긴다. 서버가 없으니 **링크 공유가 곧 구성 공유**다.

```
/#tz=Asia/Seoul,Pacific/Auckland@0700-0100&flex=3&t=2026-08-23T11:00Z
```

- `tz` — IANA 타임존 쉼표 목록. 기본과 다른 가능 시간만 `@HHMM-HHMM`으로 붙어서 평소엔 짧게 유지된다. **목록의 첫 번째가 기준(anchor)** 이라 상단 큰 시각과 하단 축 눈금이 그 지역 기준이다.
- `flex` — 여유폭(시간). 기본값 2면 생략된다.
- `t` — 절대 시각. **`Z`는 UTC+0을 뜻하고 반드시 있어야 한다** — 빼면 자바스크립트가 *여는 사람의 로컬 시간*으로 해석해서, 서울에서 만든 링크를 파리 사람이 열면 다른 순간을 보게 된다.

UTC로 담는 이유는 링크가 지역 목록과 무관하게 같은 순간을 가리켜야 하기 때문이다. 첫 번째 지역 기준으로 담으면 나중에 그 지역을 지웠을 때 링크의 뜻이 조용히 달라진다.

`tz`가 없으면 기본 4개 지역(서울·파리·산티아고·크라이스트처치), `t`가 없으면 현재 시각으로 뜬다.

## 서머타임

`Intl.DateTimeFormat`의 IANA 데이터를 그대로 쓰므로 **날짜를 바꾸면 오프셋이 따라온다.** 라이브러리 없음.

기본 4개 지역 중 셋이 서머타임을 쓰고 남반구 둘은 방향이 반대라, 8월과 1월의 시차가 서로 다르다.

| | 8/23 (UTC 11:00) | 1/23 (UTC 11:00) |
|---|---|---|
| 서울 | 20:00 | 20:00 |
| 파리 | 13:00 (CEST +2) | 12:00 (CET +1) |
| 산티아고 | 07:00 (−4) | 08:00 (−3) |
| 크라이스트처치 | 23:00 (+12) | 익일 00:00 (+13) |

**즉 답이 계절에 따라 바뀐다** — 8월에 되던 시간이 1월엔 안 될 수 있으니 잡을 때마다 날짜를 맞추고 봐야 한다.

서머타임 전환일의 23시간·25시간짜리 하루도 창 길이에 반영된다. 인도(+5:30)·채텀제도(+12:45) 같은 반시간 오프셋도 정상 동작한다.

## 로컬 실행

정적 파일이라 아무 서버나 된다.

```sh
cd public && python3 -m http.server 8777
```

## 배포

Cloudflare (b7g-blog와 같은 방식 — `wrangler.jsonc`의 assets 디렉토리).

```sh
npx wrangler deploy
```

빌드 단계가 없으므로 `public/`이 그대로 올라간다.

## 알아둘 것

- 크라이스트처치는 `Pacific/Auckland`와 같은 타임존이다. 표시 이름만 바꿔 쓴다 (`RENAME` 상수).
- 지역이 많아지고 경도가 넓게 퍼지면 Works 구간이 아예 없는 게 정상이다. 기본값의 4개 지역이 그렇고, 그때는 Maybe 구간이 답이 된다. 각자 실제 사정을 넣으면 Works가 생기기도 한다 — 크라이스트처치를 01:00까지로 늘리면 UTC 12:00–13:00에 전원 Works 구간이 나타난다.
